# 📂 案例 / Examples

真实的端到端使用案例，展示企业协作处理完整任务的全流程。

| # | 案例 | 任务内容 | 涉及部门 | 复杂度 |
|---|------|---------|----------|--------|
| 1 | [竞品分析](competitive-analysis.md) | "分析 CrewAI vs AutoGen vs LangGraph" | 中书→门下→数据部+开发部+文档部 | ⭐⭐⭐ |
| 2 | [代码审查](code-review.md) | "审查 FastAPI 代码的安全性" | 中书→门下→开发部+安全部 | ⭐⭐ |

每个案例包含：
- 📜 **任务**：原始指令
- 📋 **产品部规划**：任务拆解方案
- 🔍 **架构委员会审议**：审核意见（含封驳/返工记录）
- ⚔️ **各部执行结果**：每个部门的产出摘要
- 📮 **最终任务记录**：技术部汇总的完整报告

> 💡 这些案例基于真实运行记录整理，任务 ID 和时间戳已脱敏。
